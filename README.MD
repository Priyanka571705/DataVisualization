# Data Visualization

Python/Jupyter practice project focused on creating clear charts and visual summaries using Pandas, Matplotlib, and Seaborn.

## Category

Python, Data Analysis, Data Visualization

## What This Project Shows

- Loading and exploring a dataset in Jupyter Notebook
- Creating visualizations for patterns, comparisons, and distributions
- Practicing chart selection, labels, styling, and readable visual output
- Using Python's common data analysis stack for exploratory work

## Files

| File | Purpose |
| --- | --- |
| `Data_Visualization.ipynb` | Main notebook with visualization practice |

## Tech Stack

`Python` `Jupyter Notebook` `Pandas` `NumPy` `Matplotlib` `Seaborn`

## How To Run

```bash
git clone https://github.com/Priyanka571705/DataVisualization.git
cd DataVisualization
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook Data_Visualization.ipynb
```

Or install from the included requirements file:

```bash
pip install -r requirements.txt
jupyter notebook Data_Visualization.ipynb
```
